# Muse Launcher v1.2.2

本版本优化原生界面的账号列表、配置页和操作反馈。

- 账号列表显示当前账号、会话状态和标签；配置、重命名、删除移入右侧 ⋮ 菜单，删除仍需确认。
- 搜索支持一键清空和结果计数，收起抽屉时同时收起搜索键盘。
- 配置页分为账号资料和网络连接，统一间距和字号；输入框有焦点边框，主要按钮触控区域至少 48dp。
- 测试期间显示进度、锁定操作；成功/失败显示不同颜色和明确文本，结果自动滚动到可见区域。
- 小屏与大字体支持滚动，平板限制表单宽度；加载失败页可直接进入账号配置。
- 修复重复文案，移除无实际含义的通知圆点，更新界面渲染预览。

安装 `MuseLauncher-v1.2.2.apk`，要求 Android 10+，且系统 WebView 支持 Multi-Profile。手机 Clash 使用 VPN/TUN 时，各账号代理留空即可。

与本 fork 的 v1.2.1 使用同一签名，可直接覆盖安装并保留账号数据。如果安装的是其他签名的上游版或 debug 版，则不能直接覆盖；卸载会清除本机账号数据。

账号隔离针对 Cookie、登录状态和站点存储；不同账号仍共用真实手机，代理仍是 WebView 进程级设置。尚未完成 Android 真机验证。

新增原生布局检查，覆盖小屏、大字体、横屏、平板，以及加载失败和空页面的操作可达性。详细改动和预览见 [界面优化记录](https://github.com/544r/muse-launcher/blob/v1.2.2/docs/UI_UPDATE.md)。
