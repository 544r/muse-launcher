# Muse Launcher v1.2.3

本版本减少账号切换和状态更新时的重复操作。

- 列表按账号复用控件，状态变化只更新变化条目，避免整张列表重建。
- 页面加载完成只检查该账号的会话；返回应用时分帧检查，减少一次处理的工作量。
- 相同且已成功生效的代理配置不再重复应用，快速切换仍遵循串行顺序。
- 重复点击当前账号时不再中断页面加载；返回配置页后保留已知会话标记，避免先变为未登录再恢复。
- 增加列表复用、会话调度和代理顺序的回归测试。

安装 `MuseLauncher-v1.2.3.apk`，要求 Android 10+，且系统 WebView 支持 Multi-Profile。手机 Clash 使用 VPN/TUN 时，各账号代理留空即可。

与本 fork 的 v1.2.1 / v1.2.2 使用同一签名，可直接覆盖安装并保留账号数据。如果安装的是其他签名的上游版或 debug 版，则不能直接覆盖；卸载会清除本机账号数据。

账号隔离针对 Cookie、登录状态和站点存储；不同账号仍共用真实手机，代理仍是 WebView 进程级设置。尚未完成 Android 真机验证。

尚未测量真机帧率或与官方 App 对比的性能，不能保证消除网页内部卡顿。详细改动和验证边界见 [性能改动记录](https://github.com/544r/muse-launcher/blob/v1.2.3/docs/PERFORMANCE.md)。
