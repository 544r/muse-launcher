# Muse Launcher v1.2.4

本版本统一加入账号列表、页面切换和交互调度优化。

- 两侧账号列表改用 RecyclerView，复用屏幕附近的条目；切换账号和登录标记变化只更新对应条目。
- 会话检查等待触摸、列表滚动和抽屉动画结束后，在主线程空闲时逐个执行，减少对交互的干扰。
- 首次创建页面或切换代理时，等抽屉收起再执行；同代理下已缓存页面直接切换并保留布局尺寸。
- 加载遮罩延迟显示，页面内容可显示或加载完成后立即收起，取消额外的最短显示等待。
- 普通返回前台与文件选择返回时复用账号元数据；配置页返回仍重新读取。减少后台页面重复暂停和多层背景绘制。
- 加入独立性能测试构建与可选采样工具。正式安装包仍使用原包名和固定发布签名。

安装 `MuseLauncher-v1.2.4.apk`，要求 Android 10+，且系统 WebView 支持 Multi-Profile。与本 fork 的 v1.2.1–v1.2.3 使用同一签名，可直接覆盖安装，保留账号及站点数据，无需先卸载。

每账号 Profile、Cookie 持久化和代理切换规则继续保留。手机 Clash 使用 VPN/TUN 时，各账号代理可留空。

本地 86 项应用测试、5 项采样工具测试通过，Lint 0 错误，Debug / benchmark / release 构建通过；发布构建由 GitHub Actions 再次执行测试、Lint、构建和签名验证。

固定测试窗口下，1000 个账号的首次条目创建数从 1000 降至 6；这是工作量测试，不是真机帧率结果。本版本尚无真机性能测量，实际网页体验以设备使用为准。详情见 [性能优化记录](https://github.com/544r/muse-launcher/blob/v1.2.4/docs/PERFORMANCE_LOCAL.md)。
